# Cargo Management System

A C# Windows Forms desktop application for a basic cargo tracking and management workflow.

## Tech Stack
- C#
- .NET Framework 4.7.2
- Windows Forms
- SQL Server

## Run Locally
1. Open `kargosistemiyeni.sln` in Visual Studio on Windows.
2. Configure the SQL Server connection string in `Properties/Form1.cs` for your local SQL Server instance.
3. Create the `KargoTakip` database and the tables expected by the application.
4. Build and run the solution.

> This is an academic portfolio project. The database schema is not included. The machine-specific SQL Server name from the original development environment has been replaced with a placeholder.
